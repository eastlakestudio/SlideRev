# SlideRev 产品需求文档 (PRD)

**版本**: v1.1.0  
**状态**: 生产级规范  
**日期**: 2026-04-02  

---

## 1. 产品概述 (Product Overview)

SlideRev 是一款专为 macOS 设计的高性能 PDF 到 PPTX 转换工具。它超越了传统的“图片转 PPT”模式，通过 **AI 图像重构 (Inpainting)** 与 **智能文字层拟合** 技术，将复杂的 PDF 课件/报告转换为“背景干净、文字可编辑”的高质量演示文稿。

---

## 2. 核心功能 (Core Features)

### 2.1 增强型 OCR 与文字层拟合
- **多语言识别**：基于 Apple Vision 框架，实时提取中英文文本。
- **视觉属性仿真**：
  - **颜色采样**：自动分析文字周围像素，精确还原字体颜色。
  - **动态字号拟合**：根据 Bounding Box 自动计算最优字号 (Fitting Algorithm)。
  - **文本编辑**：转换前可直接在预览界面修改文字内容、位置、旋转角度及字号。

### 2.2 AI 智能背景重置 (AI Inpainting)
- **无感擦除**：集成 LaMa 神经网络模型，实现对文字下方背景的完美修补。
- **手动橡皮擦 (Manual Eraser)**：支持鼠标涂抹任意区域（如 Logo、页码、隐私干扰），触发异步 AI 修复。
- **透明度双轨机制**：导出时将重构后的背景作为 Slide Background，确保 PPT 原生体验。

### 2.3 批量重构流水线 (Batch Refinement)
- **全局水印清理**：支持输入关键字/正则，全局自动标记各页匹配项并执行批量擦除。
- **全量自动精炼**：一键对文档所有页面执行“OCR -> 全面擦除 -> 背景重构”的自动化流水线。
- **异步队列**：处理百页文档时 UI 保持流畅，支持后台静默执行。

### 2.4 原生导出引擎
- **PDF 导出**：生成保留原始文字层但背景已清洗的“洁净版”PDF。
- **PPTX 导出**：不依赖微软 Office 副本，原生生成 OOXML 格式的 `.pptx`。

## 3. 交互逻辑规范 (Interaction Logic)

### 3.1 页面管理
- **Reset (重置)**：瞬间回滚该页的所有修改，恢复到原始识别状态，不浪费时间重复 OCR。
- **Undo (撤销)**：支持对编辑操作进行多级撤销（LIFO 堆栈）。
- **快速翻页**：侧边栏缩略图点击即切，支持大文件快速检索。

### 3.2 视图模式
- **Original 模式**：查看 PDF 原始面貌，支持高精度缩放对比。
- **Edit 模式**：进入交互编辑态。文字框背景采用“动态显隐”逻辑：只有在鼠标悬停 (Hover) 或选中时显示蓝色提示框，避免视觉干扰。

### 3.3 手势交互 (Gestures)
- **缩放 (Zoom)**：支持 `Ctrl + 滚轮` 或触控板缩放，支持自动居中适配 (Auto-fit)。
- **平移 (Panning)**：在 Original 模式或放大状态下，支持鼠标拖拽平移视图。
- **双击魔术**：在预览区双击文字框，可快速切换该项的“擦除/显示”状态。

---

## 4. 技术特性 (Technical Specifications)

- **100% 离线隐私**：所有 AI 推理（OCR、Inpainting）均在设备本地运行，无需联网。
- **GPU 硬件加速**：利用 CoreML 与 Apple Neural Engine (ANE) 进行计算加速。
- **高性能缓存**：采用 PageState 内存环形缓存，确保在处理超大 PDF 时内存占用稳定。
- **Universal Binary**：原生支持 Apple Silicon M1/M2/M3 及 Intel 芯片。

---

## 5. 质量指标 (Quality Goals)
- **无缝背景**：修复区域与周围环境的色差 Delta-E < 2.0。
- **文本定位**：导出后的文字位置误差控制在 0.5pt 以内。
- **构建稳定性**：支持从 macOS 13.0 (Ventura) 及更高版本运行。
