# SlideRev UI/UX 设计规范 (v0.9.4)

本文件定义了 SlideRev 桌面级应用的 UI 交互标准、组件规范及视觉逻辑，旨在确保跨版本的工业设计感一致性。

## 1. 顶部工作区 (Master Ribbon)

### 1.1 布局逻辑

- **高度**：统一为 `60pt`。
- **分组**：使用 `Divider` 线条对导航、清理、操作进行物理隔离。
- **背景**：采用系统窗口色 (`windowBackgroundColor`) 配以底层微弱阴影 (`radius: 1, y: 1`)，实现悬浮层次感。

### 1.2 按钮规范 (Standard Actions)

- **统一高度**：所有带有背景色的操作按钮高度统一为 **`32pt`**。
- **圆角**：统一为 `8pt` (Rounded Corner)。
- **字体**：加粗副标题 (`.subheadline.bold()`)。
- **主要动作 (Primary)**：使用 Accent Color (Blue)。如：`Refine`。
- **批量动作 (Batch)**：使用纯蓝色背景，区别于单页操作。如：`Batch Refine`。
- **毁灭/重置 (Destructive/Neutral)**：使用系统黑色 5% 透明度背景。如：`Reset`。
- **橡皮擦 (Eraser)**：激活时背景变为 Accent Color 的 12% 透明度，并展开“笔触大小”滑动条。
- **导出 (Export)**：使用橙红渐变 (`LinearGradient`)，增强最后的“完成感”。

### 1.3 尺寸与限制 (Size Constraints)

- **窗口最小宽度**：强制为 **`1200pt`**，以容纳完整的 Master Ribbon 工具栏。
- **水印输入框**：自定义模式下宽度为 **`220pt`** (较 v0.9.4 增加 20%)。

## 2. 交互状态 (Interaction States)

### 2.1 光标系统 (Cursor System)

- **手型光标 (`.openHand`)**：在 **Original** 模式开启，且仅限图像工作区内有效。
- **箭型光标 (`.arrow`)**：在 **Editable** 模式开启，支持点选与编辑。
- **擦除模式 (Eraser)**：
  - 鼠标位置显示 **红色矩形辅助方框**。
  - 文字层自动设置 `.allowsHitTesting(false)`，允许橡皮擦手势穿透到背景层。
  - 左右键拖拽时光标变为 **闭合手形 (`.closedHand`)**。

### 2.2 文本项状态控制 (Item State Bar)

- **显示逻辑**：当文本项被鼠标悬停或选中时，在其上方/边缘显示三个功能图标。
- **三态定义**：
  - 📷 **Original**：原始背景与文本。
  - 👁️ **Cleaned**：仅 AI 修复背景，隐藏文本。
  - ✨ **Refined**：修复背景并叠加可编辑矢量文本。
- **交互冲突预防**：点击文本框主区域仅触发“选中”，不切换状态。切换状态必须显式点击控制条图标。

### 2.3 文本编辑 (Text Editing)

- **耀眼光标**：强制设置 `.accentColor(.orange)`。
- **核心逻辑**：在 **Editable** 模式下，双击或单击已选中的框进入编辑态。

## 3. 状态栏 (Status Bar)

### 3.1 核心比例

- **高度**：`32pt`。
- **组件对齐**：左侧展示版本与状态信息；中间展示页面切换；右侧展示识别与视图控制。

### 3.2 OCR 阈值控制 (OCR Threshold)

- **默认值**：`0.20`。
- **步进范围**：`0.10` 至 `0.95`。
- **逻辑**：降低阈值可捕获更多模糊文字，但也可能引入图像噪点。

### 3.3 缩放调节 (Zoom Controls)

- **刻度**：显示为百分比 (如 `100%`)。
- **复位**：点击百分比标签即可一键自动缩放 (`autoFit`) 至窗口最优尺寸。
